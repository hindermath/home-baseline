# Engineering Sessions

Dieses Verzeichnis archiviert wichtige Engineering-Sitzungen als versionierte Wissensartefakte.

## Zweck

Engineering Sessions dokumentieren nicht nur Ergebnisse, sondern auch:

- Ausgangslage und Ziele,
- Architekturentwicklung,
- getroffene und vertagte Entscheidungen,
- Review Findings,
- erzeugte GitHub-Issues und Verträge,
- Auswirkungen auf Lastenhefte, Spec Kit und Implementierung,
- offene Punkte und nächste Schritte.

Sie bilden damit eine nachvollziehbare Quelle für den Engineering Knowledge Loop.

## Qualitätsbaseline

Für neue Sitzungsdokumente gilt:

- Deutsch zuerst; Englisch kann anschließend folgen.
- Verständlich für Auszubildende der IHK-IT-Berufe ab dem 1. Ausbildungsjahr.
- Sprachniveau CEFR B2.
- Fachbegriffe werden beim ersten relevanten Auftreten erklärt oder über ein Glossar erschlossen.
- Semantische Struktur und zugängliche Darstellung gemäß den anwendbaren Zielen aus WCAG 2.2 AA.
- Entscheidungen, Annahmen, Evidenz und offene Punkte werden getrennt ausgewiesen.

## Artefaktrolle

Eine Engineering Session ist eine Wissensquelle. Sie ersetzt keine freigegebene Constitution, keinen Program Charter, kein Lastenheft und keine Specification. Bei Konflikten gelten die im jeweiligen Programm festgelegten Autoritäts- und Supersession-Regeln.
