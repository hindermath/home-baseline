# Secure-Development-Evidence / Secure Development Evidence

Dieser Pfad enthält kontextgebundene Nachweise für vier getrennte Gates:

1. baseline — geltende Quellen, Versionen und Ausgangsstand;
2. delta — Änderung und begrenzte Wirkung;
3. closure — Abschluss, Restrisiken und getrennte Freigaben;
4. image-impact — Build/Compose, Toolchain, OCI-Digest, SBOM, Secrets,
   Mounts, Netzwerk und CI.

Jeder Prüfpunkt trennt Anwendbarkeit (Applicable, N/A, Open) und Umsetzung
(Fulfilled, Partly Fulfilled, Not Fulfilled, Not Assessed). Zulässige
Ergebnisse sind Ready, ReadyWithAcceptedRisks, NeedsRemediation und Blocked.

Technische Validierung, Pilotfreigabe, Projektabnahme und allgemeine Sandbox-,
Produkt- oder Flottenfreigabe sind eigenständige Entscheidungen. HOSK/GWDG ist
nur externer Vergleich; seine Dokumente sind niemals lokale Evidence.

## English

Each context records baseline, delta, closure, and image-impact gates.
Applicability and implementation are separate axes. Technical validation does
not grant a pilot, project, product, sandbox, or fleet authorization.
HOSK/GWDG remains external comparison material only.
