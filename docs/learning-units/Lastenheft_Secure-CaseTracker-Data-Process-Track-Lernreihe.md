# Lastenheft: Secure CaseTracker Data & Process Track Lernreihe

## Zweck / Purpose

**DE:** Dieses Master-Lastenheft beschreibt den DPA - Daten- und Prozessanalyse-Track als Gesamtlandkarte. Es ist nicht dafür gedacht, als einzelner großer Spec-Kit-Lauf gestartet zu werden.

**EN:** This master intake describes the Data and Process Analysis track as an overview map. It is not meant to be started as one large Spec Kit run.

## Zielgruppe / Target Group

| Merkmal / Aspect | Einordnung / Classification |
|---|---|
| Lehrjahr / Training year | ab dem 3. Lehrjahr |
| Spezialisierung / Specialization | DPA - Daten- und Prozessanalyse |
| MSL-Sprachen | C#, Go, Java, Python, Rust, Swift |
| Sprache / Language | DE-first, EN-second, CEFR B2 |
| Barrierefreiheit / Accessibility | WCAG 2.2 AA, textfreundliches Markdown |

## Gesamtziel / Overall Goal

**DE:** Der Data & Process Track nutzt CaseTracker-Daten für nachvollziehbare Prozessanalyse. Lernende planen Datenbedarf, Qualität, Datenschutz, Kennzahlen, Reporting, Audit-Evidence, Bias-Risiken und Handlungsempfehlungen.

**EN:** The Data & Process Track uses CaseTracker data for traceable process analysis. Learners plan data needs, quality, privacy, metrics, reporting, audit evidence, bias risks, and recommendations.
