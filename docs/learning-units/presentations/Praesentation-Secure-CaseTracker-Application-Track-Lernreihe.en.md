# Secure CaseTracker Application Track

## Application Development specialization from the third training year onward

EuFPA - European Company Programs Everything

DE-first/EN-second · CEFR B2 · WCAG 2.2 AA

::: notes
This presentation introduces the track. It does not replace a Spec Kit run and does not create repositories.
:::

---

# Track goal

- The Application Track extends the CaseTracker functionally and technically. Learners plan professional features, architecture decisions, API compatibility, secure feature gates, a test pyramid, and security ADRs.
- The track builds on Secure CaseTracker and Secure CaseTracker v2.
- Later work stays separated by language path and task intake.
- C#, Go, Java, Python, Rust, and Swift remain prepared as MSL paths.

---

# Task sequence

- 01: Erweiterungs-Scope und Fachdomäne
- 02: Modul- und Komponentenarchitektur
- 03: API-Versionierung und Kompatibilität
- 04: Rollen, Rechte und sichere Feature-Gates
- 05: Validierung, Fehlerbehandlung und Response-Modell
- 06: Persistenz, Migrationen und Datenintegrität
- 07: Testpyramide und Negativtests
- 08: Secure Coding pro MSL-Pfad
- 09: Security-ADR und Architektur-Trade-offs
- 10: Abschlussreview mit Restrisiken und Übergabe
