**DE:** Dieses Register macht sichtbar, welche Lernreihen existieren, für welches Lehrjahr sie gedacht sind und wo ihre kanonischen Dateien liegen.

**EN:** This register shows which learning series exist, which training year they target, and where their canonical files live.

## Statuswerte / Status Values

| Status | Bedeutung / Meaning |
|---|---|
| geplant / planned | Thema ist vorgesehen, aber noch nicht ausgearbeitet |
| vorbereitet / prepared | Lernmaterial und Intakes liegen vor, Spec-Kit-Läufe sind noch offen |
| aktiv / active | Lehrende oder Lernende bearbeiten die Reihe |
| abgeschlossen / completed | Reihe wurde bearbeitet und ausgewertet |

**EN:** New learning series are registered here first and then built from the [Learning Series Blueprint](Lernreihen-Blueprint.md). Secure CaseTracker remains the reference for structure, depth, and packaging. Secure CaseTracker v2 and Secure InventoryHub show the pattern for second-year series.
