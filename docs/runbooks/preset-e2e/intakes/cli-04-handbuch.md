# Vorlage 4: CLI-Handbuch / Template 4: CLI handbook

**Status:** Inaktive Vorlage. Erst nach belegtem Abschluss der TUI instanziieren und prüfen.

**EN status:** Inactive template. Instantiate and review it only after the TUI has a proven completion.

## Deutsch

**Auftrag:** Schreibe eine versionierte, textorientierte Anleitung für CLI und TUI. Erzeuge daraus ein Handbuch als PDF. Erkläre Installation, Aufruf, Grundrechenarten, Fehler, Tests und Tastaturbedienung für Menschen ohne Spec-Kit-Vorkenntnisse. Der vollständige deutsche Teil steht vor dem gleichwertigen englischen Teil; beide sind ungefähr CEFR B2.

**Abnahme:** Quelltext und PDF beschreiben denselben geprüften Stand. Prüfe im PDF Struktur, Dokumentsprache, Überschriften, Lesereihenfolge, Links und Textalternativen. Dokumentiere automatische und praktische A11Y-Prüfungen getrennt, einschließlich nicht geprüfter Kriterien. Gib keine pauschale WCAG-2.2-AA-Konformität ohne entsprechenden Nachweis an.

**Abhängigkeit:** Bindend nach CLI-Vorlage 3; Abschluss der Serie.

## English

**Request:** Write a versioned text-first guide for CLI and TUI and generate a PDF handbook from it. Explain setup, invocation, operations, errors, tests and keyboard use to people without Spec Kit experience. Complete German comes before equivalent English; both target about CEFR B2.

**Acceptance:** Source and PDF describe the same tested revision. Check PDF structure, language, headings, reading order, links and text alternatives. Record automated and practical accessibility reviews separately, including untested criteria. Do not claim overall WCAG 2.2 AA conformance without supporting evidence.

**Dependency:** Binding after CLI template 3; closes the series.
