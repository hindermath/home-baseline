# Vorlage 3: TUI / Template 3: TUI

**Status:** Inaktive Vorlage. Erst nach belegtem Abschluss der CLI-Tests instanziieren und prüfen.

**EN status:** Inactive template. Instantiate and review it only after the CLI tests have a proven completion.

## Deutsch

**Auftrag:** Erstelle ein Terminal User Interface (TUI) als Frontend für die vorhandene Rechenlogik in `<MSL>`. Es zeigt Operanden, Operation, Ergebnis und Fehler als Text und ist vollständig per Tastatur bedienbar. Die CLI bleibt verfügbar.

**Abnahme:** Prüfe Fokus- und Bedienfolge, alle vier Operationen, Fehler und eine nicht interaktive Prüfung der Rechenlogik. Halte Terminal, Plattform, Tastaturprüfung und – falls verfügbar – Beobachtungen mit Screenreader oder Braille-Zeile getrennt fest. Farben oder Symbole dürfen allein keine Information tragen.

**Abhängigkeit:** Bindend nach CLI-Vorlage 2. Das Handbuch folgt.

## English

**Request:** Create a terminal user interface (TUI) as a frontend for the existing `<MSL>` calculator logic. Show operands, operation, result and errors as text and make every action available by keyboard. Keep the CLI available.

**Acceptance:** Check focus and interaction order, all four operations, errors and a non-interactive domain-logic test. Record terminal, platform, keyboard review and, when available, screen-reader or Braille observations separately. Colour or symbols must not carry information alone.

**Dependency:** Binding after CLI template 2. The handbook follows.
