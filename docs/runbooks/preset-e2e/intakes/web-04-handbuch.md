# Vorlage 4: Web-Handbuch / Template 4: Web handbook

**Status:** Inaktive Vorlage. Erst nach belegtem Abschluss der Weboberfläche instanziieren und prüfen.

**EN status:** Inactive template. Instantiate and review it only after the web UI has a proven completion.

## Deutsch

**Auftrag:** Schreibe eine versionierte, textorientierte Anleitung für lokalen Start, HTTP-Vertrag, Weboberfläche, Fehler, Tests und Tastaturbedienung. Erzeuge daraus ein PDF-Handbuch. Der vollständige deutsche Teil steht vor dem gleichwertigen englischen Teil; beide sind ungefähr CEFR B2 und erklären Fachbegriffe beim ersten Auftreten.

**Abnahme:** Quelltext und PDF beschreiben denselben geprüften Stand. Prüfe im PDF Struktur, Dokumentsprache, Überschriften, Lesereihenfolge, Links und Textalternativen. Dokumentiere automatische und praktische A11Y-Prüfungen getrennt, einschließlich nicht geprüfter Kriterien. Gib keine pauschale WCAG-2.2-AA-Konformität ohne entsprechenden Nachweis an.

**Abhängigkeit:** Bindend nach Web-Vorlage 3; Abschluss der Serie.

## English

**Request:** Write a versioned text-first guide for local startup, HTTP contract, web UI, errors, tests and keyboard use. Generate a PDF handbook from it. Complete German comes before equivalent English; both target about CEFR B2 and explain terms on first use.

**Acceptance:** Source and PDF describe the same tested revision. Check PDF structure, language, headings, reading order, links and text alternatives. Record automated and practical accessibility reviews separately, including untested criteria. Do not claim overall WCAG 2.2 AA conformance without supporting evidence.

**Dependency:** Binding after web template 3; closes the series.
