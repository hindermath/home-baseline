# Vorlage 3: Weboberfläche / Template 3: Web UI

**Status:** Inaktive Vorlage. Erst nach belegtem Abschluss der HTTP-Tests instanziieren und prüfen.

**EN status:** Inactive template. Instantiate and review it only after the HTTP tests have a proven completion.

## Deutsch

**Auftrag:** Ergänze eine barrierefrei gedachte Webseite als Frontend für die vorhandene Rechenlogik in `<MSL>`. Zwei Eingabefelder, die Operation, das Ergebnis und Fehler sind verständlich beschriftet. Die HTTP-Schnittstelle bleibt unabhängig prüfbar.

**Abnahme:** Prüfe alle vier Operationen, `1 / 2 = 0.5`, Fehler, Tastaturbedienung, Fokusfolge, Formularkennzeichnung, Statusansage und Textalternativen. Eingaben werden validiert und Ausgaben sicher dargestellt. Dokumentiere verwendeten Browser und Hilfsmittel; nicht durchgeführte praktische Prüfungen bleiben offen.

**Abhängigkeit:** Bindend nach Web-Vorlage 2. Das Handbuch folgt.

## English

**Request:** Add an accessibility-minded web page as a frontend for the existing `<MSL>` calculator logic. Clearly label the two inputs, operation, result and errors. Keep the HTTP interface independently testable.

**Acceptance:** Check all four operations, `1 / 2 = 0.5`, errors, keyboard use, focus order, form labels, result announcements and text alternatives. Validate input and render output safely. Record the browser and assistive tools used; leave practical checks that were not performed open.

**Dependency:** Binding after web template 2. The handbook follows.
