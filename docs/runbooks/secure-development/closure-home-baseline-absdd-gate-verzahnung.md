# Runbook: Closure-Gate

Kontext: home-baseline-absdd-gate-verzahnung
Modi: training, mixed, development

1. Prüfe lokale Tests, Secret-Scan, Dokumentation, Links und Draft-PR-Checks.
2. Erfasse technische Validierung separat.
3. Erfasse Pilotfreigabe nur durch die benannte Pilot-Authority.
4. Erfasse Projektabnahme nur durch den ABSDD-Owner.
5. Erfasse allgemeine Sandbox-, Produkt- oder Flottenfreigabe nur durch die
   hierfür benannte Authority.
6. Melde NeedsRemediation, solange eine erforderliche Entscheidung offen ist.

## English

Close technical evidence without collapsing the three human authorization
boundaries. Open decisions prevent Ready.
