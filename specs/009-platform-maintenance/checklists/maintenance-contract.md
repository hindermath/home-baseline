# Maintenance Contract Checklist

- [x] CHK-M01 Exakte Flottengröße und Wartungsklassen sind definiert.
- [x] CHK-M02 Collection und Git-Ziele sind getrennt modelliert.
- [x] CHK-M03 Clone-on-missing besitzt eine transaktionale Grenze.
- [x] CHK-M04 Dirty, Ahead, Diverged, Detached und PathConflict sind fail-closed.
- [x] CHK-M05 Check-only, Preview und Update sind unterscheidbar.
- [x] CHK-M06 Fehler blockieren nur abhängige Stufen.
- [x] CHK-M07 Bericht und Log bleiben nach isolierten Fehlern verfügbar.
- [x] CHK-M08 Bash-/PowerShell-Parität umfasst Entscheidungen und Evidence.
- [x] CHK-M09 No-op und Admin-Deferred sind explizite Prüffälle.
- [x] CHK-M10 Position-4-Scope wird nicht vorweggenommen.
- [x] CHK-M11 Ziel-Repositories erhalten keine Commits oder Pushes.
