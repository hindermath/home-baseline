# Quickstart

1. Run `$speckit-intake-create-status`.
2. Resolve `NeedsClarification` or `Blocked` decisions.
3. Review a proposed operation and grant bounded update authority.
4. Run `$speckit-intake-update`.
5. Run Intake Review, Series Status, and Series Next.
6. Confirm one `Eligible` candidate and remember that this is no delivery
   permission.
