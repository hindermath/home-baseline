# Contract: Requirements Intake Governance 2.0

Schema 1.0 remains readable and reports `MigrationRequired`. Writes require
current explicit authority. Existing names remain unless rename authority is
separately present. Stable error families cover schema, language, profile,
path, role, inventory, reference, hash, order, eligibility, authority,
collision, transaction, rollback, and repair. Status and next-selection
commands are strictly read-only.
