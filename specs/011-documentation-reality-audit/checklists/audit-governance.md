# Audit Governance Checklist

## Scope and evidence

- [x] Level 0 and every frozen target have one repository outcome.
- [x] Every documentation family has one primary decision.
- [x] Positive claims cite exact current evidence.
- [x] Findings have severity, owner, residual risk, boundary, trigger, handoff.
- [x] No fleet repository was changed.

## Security and architecture

- [x] NIST SSDF and CWE Top 25 evidence hygiene reviewed.
- [x] ASVS, SBOM, VEX, SLSA, AI-SBOM and regulatory N/A rationale recorded.
- [x] STRIDE/CIA/CAPEC, S-ADR, arc42, Zero Trust, SAMM, BSI C3A/C5 boundaries recorded.
- [x] Secret scan and private-path checks pass.

## Learners and accessibility

- [x] Reports are DE-first/EN-second where user-facing and CEFR B2.
- [x] First-use terms are explained.
- [x] Decisions, dependencies, blockers, and handoffs are text-first.
- [x] Applicable WCAG 2.2 AA review is recorded.

## Delivery

- [x] Statistics and feature evidence are current.
- [ ] Intake is archived without starting D2.
- [ ] Exact-head gates and review threads converge.
- [ ] Local `main` is clean and equals `origin/main`.
