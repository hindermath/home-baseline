# Contract: Agentic Workspace Efficiency Guide Acceptance

## Inputs

- Binding D6 intake and accepted review.
- Merged Feature 018-021 evidence.
- Current wrapper help, PowerShell help, manpage, script reference, report
  schema and TUI contracts.
- Existing DE/EN root portals and four reader paths.

## Outputs

1. Paired DE/EN canonical efficiency guide.
2. Four synchronized reader-path integrations.
3. Source matrix conforming to the feature data model.
4. Deterministic validator with positive and isolated negative fixtures.
5. Human semantic, A11Y, platform and Documentation Impact evidence.

## Acceptance Rules

- Every operational claim has exactly one primary current source or is marked
  solely as a historical boundary.
- All documented option tokens and exit codes match current public surfaces.
- Check, preview and real-run examples identify effects and authority.
- Report plus process exitcode remain completion truth; JSONL is live evidence
  only and degraded streams are never promoted to success.
- All four reader paths and their language partners are reachable and
  materially equivalent.
- `sourceOnly` delivery creates no Home-sync obligation.
- The final product diff contains no executable maintenance, preset, registry,
  dependency, workflow or target-repository behavior change.
- A runtime follow-up is created only for a reproducible non-documentation gap.
- D7 is not started by Feature 022.

## Rejection Rules

Reject acceptance for duplicate/missing claim IDs, stale hashes, unresolved
paths or anchors, unsupported options/status values, visual-only state meaning,
an unbounded efficiency claim, missing language parity, incomplete
Documentation Impact or any executable-scope change.
