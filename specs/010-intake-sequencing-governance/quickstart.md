# Quickstart: Intake Sequencing Governance

1. Install the optional preset at priority 66.
2. Create a series only from explicitly named existing intakes.
3. Run status to validate manifest, receipt, hashes, graph, and lifecycle.
4. Use read for a learner-friendly summary.
5. Use next to list eligible targets; it does not start them.
6. Use update or delete only with explicit current authority.
7. Hand a selected, independently reviewed intake to a separately authorized
   downstream workflow.

```text
$speckit-intake-series-create Create a series from ...
$speckit-intake-series-status
$speckit-intake-series-next
```
